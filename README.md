# Future Interns Task 1 – Business Sales Performance Analytics

## 📊 Project Overview

This project was completed as part of the Future Interns Data Science & Analytics Task 1.

The objective is to analyze business sales data and create a dashboard that provides useful insights into sales, profit, products, categories, and regions.

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products.
- Analyze sales trends over time.
- Compare sales across different categories.
- Compare sales performance across regions.
- Provide actionable business recommendations.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Visualization
- GitHub

## 📁 Dataset

Dataset used: Superstore Sales Dataset

The dataset contains information about products, categories, regions, sales, profit, orders, and other business-related fields.

## 📈 Dashboard

"Business Sales Performance Analytics Dashboard" (./Screenshot%202026-10-05%20104208.png)

## 💡 Key Business Insights

1. Technology is the highest-performing category based on sales.
2. The West region has the highest sales performance.
3. East is another strong-performing region.
4. Central and South regions have opportunities for improving sales.
5. Sales fluctuate over time, with certain periods showing noticeable sales peaks.

## 💼 Business Recommendations

- Focus marketing and inventory efforts on the Technology category.
- Continue strengthening sales strategies in the West and East regions.
- Develop targeted promotions to improve performance in Central and South regions.
- Maintain sufficient stock for high-performing products.
- Analyze high-sales but low-profit products to improve profitability.
